# 🧪 Ibuprofen Chiral Analysis App

An interactive web application built with Python to visualize, analyze, and explore the chiral properties, molecular structures, and enantiomers of Ibuprofen.

---

## ✨ Features
- **Molecular Visualization:** Interactive 3D/2D structural visualization of (R)- and (S)-ibuprofen enantiomers.
- **Chiral Property Analysis:** Overview of chemical properties, stereochemistry, and biological activity differences.
- **Interactive UI:** Dynamic web interface for seamless molecular exploration.

---

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **Framework & Libraries:** Streamlit / Dash, RDKit, Py3Dmol (configured via `requirements.txt`)

---
